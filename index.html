同步到电脑台账

数据存在本机浏览器里，电脑休眠也能记。电脑上线后：点「生成同步文本」→「复制」→ 粘贴发给小Q，即可入台账。带「照片n」标记的记录：同步后把对应照片在聊天里补发（注明日期＋餐次），小Q会读标签/份量核对修正。

备份 / 恢复

换手机或清浏览器前先导出 JSON 备份；新环境用导入恢复。注意：备份不含照片，照片只存本机浏览器。

使用说明

1. 用浏览器打开本文件，建议「添加到主屏幕」当 App 用。
2. 顶部选日期＋训练日/休息日，汇总卡实时对照目标区间。
3. 饮食/运动点模板一键记，或自定义；每日和身体按天覆盖保存。
4. 记完不用管电脑是否在线；方便时到「同步」页复制文本发给我。
5. 不要清浏览器数据；定期导出 JSON 备份更稳妥。
